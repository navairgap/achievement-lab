# achievement-lab
achievements playground

## Purpose

this repo exists for one evening's experiment: learning how github achievements trigger. nothing here is a product; the real work lives in the other repos. archived in spirit, left public as the receipt.

## Epitaph

the lab earned two badges and taught one lesson: the ones that count can't be scripted. archived as the receipt — see the profile showcase for the survivors.


## Data integrity

Keep verified GitHub achievements distinct from custom README graphics. Record provenance for imported facts, represent unknown values as unknown, and never infer achievement status from a decorative badge.
